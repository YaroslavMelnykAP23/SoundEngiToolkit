# Тестування

Автоматичних тестів у репозиторії поки немає (вимога R-26). Нижче: команди, які використовуються або мають використовуватися, і обов'язкові сценарії.

## Передумови

- Android Studio, реальний пристрій (рекомендовано) або емулятор із віртуальним мікрофоном.
- Налаштоване середовище: [README.md](README.md), розділ «Налаштування».
- Без `google-services.json` додаток запускається, але хмарний AI недоступний (працюють правила).

## Команди

Виконуються з кореня проєкту (Windows: `gradlew` замість `./gradlew`).

| Команда | Призначення |
|---|---|
| `./gradlew assembleDebug` | збірка debug-APK |
| `./gradlew test` | unit-тести (JVM) |
| `./gradlew connectedAndroidTest` | інструментальні тести на пристрої або емуляторі |
| `./gradlew lint` | статичний аналіз Android Lint |
| `./gradlew signingReport` | показує SHA-1 для налаштування ключа Google |

## Рекомендовані unit-тести (не написані)

- `Ai.apply`: коректні й некоректні JSON, невідомий `fx`, відсутні поля.
- `RulesSource`: фрази з BPM, `1/8`, «компресор», «reverb»; порожній результат для нерозпізнаних.
- `Delay.sync`: 1/8 при 120 BPM = 0.25 с = 11025 семплів.
- `Sampler.run`: зупинка в кінці, loop у межах A-B, перехід у `loopStart`.
- `Engine.scope`: вирівнювання по переходу через нуль на синтетичному сигналі.
- `columns()`: мінімум, максимум, пік, RMS на відомому масиві.
- `Wav.write` + `Wav.read`: повторення з похибкою не більше 1/32768; файл має 2 канали, розмір даних = 4 байти на семпл; читання mono-WAV і stereo-WAV з різними каналами (усереднення); відхилення не-WAV файлу та частоти не 44100 Гц.
- `FxState.toJson` + `FxState.apply`: збережені параметри збігаються після відновлення.
- `ProjectDao`, `AiDao` (instrumented, Room in-memory): вставка, сортування, `trim` залишає 200 записів.

## Обов'язкові ручні сценарії

Запускати на реальному пристрої (емулятор дає велику затримку й може не мати мікрофона).

1. **Запис.** Дозвіл на мікрофон запитується. Record → Stop → статус `Recorded N s`, осцилограф показує весь запис.
2. **Відсутній дозвіл.** Відхилити дозвіл: з'являється зрозуміле повідомлення, додаток не падає.
3. **Відтворення.** Тап ставить курсор (блакитна лінія), `Play from cursor` грає звідти; тап під час відтворення перестрибує.
4. **Loop.** Перетягнути маркери A і B, увімкнути Loop A-B: фрагмент зациклюється без клацань; Snap to beats притягує до бітів.
5. **Сітка.** Змінити BPM: лінії бітів і тактів перебудовуються; при сильному віддаленні лінії розріджуються.
6. **Масштаб.** Пінч, перетягування, слайдер Zoom, `Fit all` повертає весь сигнал; новий запис автоматично показується цілком.
7. **Клавіші.** Затискання клавіші дає звук, відпускання плавно його вимикає; режим Live показує форму хвилі.
8. **Ефекти.** Перемикачі Delay, Compressor, Reverb змінюють звук на записі й на клавішах.
9. **Volume.** Слайдер −60…+12 дБ змінює гучність без клацань; −60 повністю вимикає звук.
10. **AI офлайн.** Команда за замовчуванням з UI вмикає Delay і Compressor та ставить BPM 120 без Firebase.
11. **AI без налаштованого Firebase.** Нерозпізнана фраза не призводить до падіння.
12. **Життєвий цикл.** Згорнути й розгорнути додаток під час відтворення: додаток не падає. Поворот екрана: додаток не падає, але запис і налаштування скидаються (відоме обмеження L-13). Закриття не залишає звуку.

13. **Save.** Записати звук → `Save` → ввести назву → статус `Saved: <назва>`; запис зʼявляється у списку. Збережений WAV відкривається на комп'ютері як stereo 16 біт 44.1 кГц, звучить однаково в обох каналах. Save без запису або під час запису показує підказку, а не падає.
14. **Load.** Змінити BPM, ефекти, маркери → `Load` збереженого запису: звук, BPM, перемикачі ефектів, курсор і loop-маркери відповідають моменту збереження.
15. **Після перезапуску.** Повністю закрити додаток і відкрити знову: збережені записи є в списку й відтворюються.
16. **Delete.** `Delete` показує підтвердження; після підтвердження запис зникає зі списку, файл видаляється з пристрою.
17. **Історія AI.** Виконати команду: у `AI history` зʼявляється запис із джерелом (rules або cloud); тап по запису підставляє запит у поле; `Clear` очищає список. Нерозпізнана фраза записується з ✗.
18. **Вкладки.** Зберегти кілька записів: у Studio список не показується, на вкладці Library видно всі; лічильник у назві вкладки збігається. Load зі вкладки Library повертає на Studio з відновленими курсором і маркерами. Під час запису перехід на Library неможливий.
## Критерій проходження

Усі сценарії 1-17 проходять на реальному пристрої без падінь; `./gradlew assembleDebug` і `./gradlew lint` без помилок.
